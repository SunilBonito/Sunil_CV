Projects & Initiatives

Six tools I designed, built, and deployed to production over the last year, solving real operational problems inside iLab and the wider Bonito Designs organisation. Each replaced a manual process or WhatsApp workflow with a real-time, shared, auditable system. Tap any card to see what's inside.

Live · in daily use

iLab Department Task Manager

Real-time task management PWA replacing WhatsApp-based coordination for the iLab Design and Category teams. Working-day TAT tracking, push notifications, management dashboard, Excel export.

React Vite Firebase FCM Netlify PWA
View details
  • Two-team architecture (Design + Category) with email-based member login and password-based management access
  • Real-time sync across all devices via Firebase Firestore listeners
  • TAT calculated on working days only (excludes Sundays and 1st/3rd/5th Saturdays per company calendar)
  • Push notifications via Firebase Cloud Messaging with VAPID keys; WhatsApp deep-link for management follow-up
  • 3-sheet Excel export: all tasks with comments + end-date history, team summary with month-wise completion %, tickets log
  • Installable on Android and iOS via PWA manifest; session persistence so members stay logged in
  • Rolled out and in daily use by both Design and Category teams
Live · ISO audit support

Experience Centre Audit System

Multi-location material audit tracker covering ~12,000 SKUs across four EC locations. Excel-based audit trackers feed a live web dashboard that reads directly from GitHub-hosted files.

HTML SheetJS Chart.js GitHub Pages Excel
View details
  • Four location-specific Excel files (Andheri, Thane, HSR, HRBR) with 12 category sheets each, 5 audit-round blocks per category, dropdown validations, auto-status formulas, conditional formatting

  • Location filter, audit-round tabs, location progress cards (OK / Check / Action / RBS / Pending pills)

  • Six compliance KPI cards: completion %, SKUs audited, closure compliance, target gap, issue closure rate, best location
  • Two-sheet Excel download for flagged items and common missing samples grouped by category

Material Audit Scanner

Apps Script Google Sheets html5-qrcode GitHub Pages
