01 CATEGORY ANALYTICS

PKO Sales Dashboard

The Problem

Sales data lived in dense ERP exports nobody could read in time. Dead stock, fast and slow movers, and brand level performance were invisible until month-end reviews, by which point the inventory decisions had already been made on intuition.

The Solution

A live sales analytics dashboard that reads CSVs straight from the source. Robust ERP matching (case normalisation, whitespace handling, variant collapsing) means product families aggregate correctly. Filters by branch, brand, category and date cross-filter every visual instantly.

02 ISO AUDIT SUPPORT

Experience Centre Audit System

The Problem

Material library audits across four Experience Centres meant manually reconciling spreadsheets, chasing photos on WhatsApp, and rebuilding the same compliance view every audit round. ISO readiness was a recurring fire drill.

The Solution

Four location-specific Excel files with 12 categories each and 5 audit-round blocks, feeding a live web dashboard that reads them directly from GitHub via SheetJS. Location filters, round tabs, completion charts, status breakdown, and six compliance KPI cards stay in sync automatically.

03 CUSTOMER INTELLIGENCE

NPS Intelligence Dashboard

The Problem

Monthly NPS reporting was a manual exercise: pull two CSVs, build pivots, format for the leadership review, repeat. By the time numbers reached anyone, the fortnight had already turned over and the chance to act on a detractor was gone.

The Solution

Drop-in CSV refresh dashboard tracking Overall and Design NPS across branches, designers, project managers and CRMs. Six analytical views with fortnight cycles aligned to company definition. People leaderboards apply a 5-response minimum so a single lucky review can't skew the rankings.

04 ON-FLOOR OPERATIONS

Material Audit Scanner

The Problem

Auditing thousands of materials across four Experience Centres on paper was slow and error-prone. Handle and hardware families had multiple sizes, each scanned separately and duplicating work, while discontinued items kept reappearing in library counts.

The Solution

Camera-based QR scanner app running off Google Sheets and Apps Script. Smart family detection auto-marks variants as Representative Sample. Discontinued items get flagged on scan instead of overwriting status. Auto-incrementing audit numbers, duplicate-scan prevention, A3 QR-label PDF generator.

05 TEAM COORDINATION

iLab Task Manager

The Problem

Task coordination across the iLab Design and Category teams ran on WhatsApp. Threads buried, deadlines forgotten, no way to track turnaround time, no visibility for management. Every status check was a manual chat scroll.

The Solution

A real-time Progressive Web App built on React and Firebase. Two-team architecture with email login. Working-day TAT (excludes Sundays and 1st/3rd/5th Saturdays per company calendar). Push notifications, three-sheet Excel export, WhatsApp deep-link for management follow-up.

06 BRAND OPERATIONS

iLab Email Template System

The Problem

iLab launch and update emails went out in every shape and style. Inconsistent branding, broken layouts on Outlook, hours rebuilt every time. New team members had to learn HTML or wait on a designer to get a single update out.

The Solution

Two reusable branded HTML templates (Launch and Update), exported as Outlook .oft files so anyone can open them in Outlook and edit like Word. A designer cheat sheet covers image replacement, common gotchas, and maintenance. Hosted in a shared SharePoint folder.
